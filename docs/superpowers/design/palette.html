08

Typography Specimen

Display: Baloo 2 (swapped in from Mochibop — that font's demo license explicitly forbids use in games, so it can't be embedded; Baloo 2 is the closest OFL match: same bubbly, chunky-rounded weight, full Indonesian Latin coverage). Body/caption/micro: Nunito throughout, as requested.
