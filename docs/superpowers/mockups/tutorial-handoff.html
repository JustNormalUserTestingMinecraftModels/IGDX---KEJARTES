Interactive — the real screen sits underneath, dimmed; the spotlight lands on actual controls.

What this is

A replacement for the Grade-7 onboarding, which today is 14 sequential text cards. It teaches by showing and doing instead of reading, voiced by the headmaster, laid over the live screen.

Non-negotiables

  • It is an overlay, not a new scene. A CanvasLayer dims the live StudentCard / AturJadwal and cuts a spotlight hole over the real control — the shipped TutorialPanel spotlight, arrow and wrong-tap shake already do this.
  • One voice, one box everywhere: the "Nota Guru" torn-note dialogue box (build it as a NotebookFrame variant so test_popup_frames.gd keeps guarding it).
  • Touch-first, no hover. Every cue fires on tap or an inactivity timer; targets ≥44px; nothing relies on pointer-enter.
  • No persistence added beyond a session flag; respects GameState.tutorials_bypassed and the "Lewati Dialog Minigame" setting for typewriter skip.
  • No emoji as iconography — drawn SVG. Art (mascot expressions, paperclip, hand, comic plates) ships as drop-replaceable placeholders.

The first-run flow

  1. Misi (cold-open, 3 beats). Full dim, centered comic plate states the goal: "Capai minimal 2 dari 3 target → lulus" then the stakes "satu murid gagal, satu kelas kena nilai D." Tap anywhere.
  2. Kenalan (3 spotlights). One traveling note hops Mood → Energi → Skill on the real card; each a short line. Replaces ~7 old text cards.
  3. Sifat (handoff). Spotlight the Quirk/Persona badges; tapping one hands off to the real trait popup (see the overlap rule).
  4. Jadwal (learn-by-doing). On the real AturJadwal screen, the player assigns Senin and the bars move live with floating deltas.
  5. Mulai. Spotlight Approve; tap to finish into the first week.

Advancing & the overlap fix

Advance

Teaching/comic beats show the blinking KETUK DI MANA SAJA UNTUK LANJUT prompt and advance on a tap anywhere on the dimmed screen. Action beats (badge, activity, Approve) gate on that one real control, then switch to the prompt.

One focal box (the bug you flagged)

The coach note and any game popup are mutually exclusive. Tapping a badge makes the note tuck away (slide down + fade) before the trait popup springs in; closing the popup slides the note back with the follow-up line. Never both on screen. Z-order backstop: the coach layer sits below game popups regardless.

Idles (catch a stuck player)

  • Resting loops, always on: note sway ±1.4°, mascot breathe + blink, a soft highlight ring, breathing CTA.
  • Escalation nudge after idle_nudge_seconds (default ~2.5s) of no input: pointing hand slides in, target wiggles harder, ring intensifies, Pak Kepsek drops a one-liner. Any tap resets it.
  • Capped at one level (no endless nagging). Pauses while a popup/comic/beat is on screen.

Scope

Shared system — every tutorial screen, Lobby included: adopt the Nota Guru box, tap-anywhere prompt, one-focal-box rule, idle tiers and touch-first behavior, so no screen looks like the old style. Keep each screen's current teaching content; only re-skin and re-behave it.

Deep redesign — Grade-7 first-run only (StudentCard + first AturJadwal): the comic cold-open and learn-by-doing beats above.
